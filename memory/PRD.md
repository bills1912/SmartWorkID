# KerjaAI - Platform Digitalisasi Penciptaan Lapangan Kerja

## Overview
AI-powered job matching and workforce development platform for Indonesia. Differentiates from traditional job boards (JobStreet, Glassdoor, Upwork) through deep AI-powered features.

## Key Differentiating Features (NEW)
1. **AI Prompting Search** (/ai-search) - Conversational AI job search using natural language. Users describe their profile and AI recommends jobs with detailed reasoning.
2. **Deep AI Match Analysis** - Multi-dimensional compatibility analysis (6 dimensions: Skill, Experience, Culture, Salary, Growth, Location) with radar chart and AI summary.
3. **Career Path Analyzer** (/career-path) - Interactive career roadmap with branching paths, skill gaps per stage, salary projections, and timeline.

## Core Features (from original spec)
4. **Skill Gap Advisor** (/skill-advisor) - Analyze skills vs market requirements with radar charts
5. **Personalized Training** (/training) - Learning paths with course catalog, enrollment, progress tracking
6. **Matching Antarwilayah** - Cross-regional job matching across Indonesia

## Pages (7 total)
- Landing Page (/) - Marketing page with comparison table vs competitors
- AI Job Search (/ai-search) - Chat-based conversational AI job search
- Jobs (/jobs) - Job listings with filters + AI analysis dialog tab
- Career Path (/career-path) - Interactive career roadmap analyzer
- Dashboard (/dashboard) - Analytics overview with charts
- Skill Advisor (/skill-advisor) - AI skill gap analysis
- Training (/training) - Course catalog with enrollment

## Tech Stack
React + Tailwind CSS + shadcn/ui + Framer Motion + Recharts

## Data
All data is MOCKED on the frontend (no backend API calls). This is a frontend prototype.
