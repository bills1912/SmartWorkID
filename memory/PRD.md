# KerjaAI - Platform Digitalisasi Penciptaan Lapangan Kerja

## Overview
AI-powered job matching and workforce development platform for Indonesia. Connects job seekers with employers through intelligent matching, skill gap analysis, personalized training, and cross-regional job discovery.

## Core Features (from user requirement)
1. **AI Job Matching** - Smart matching between job seekers and opportunities
2. **Skill Gap Advisor** - Analyze skills and recommend improvements
3. **Personalized Training** - Learning paths tailored to individual needs
4. **Workforce Analytics** - Dashboard showing job market insights
5. **Cross-regional Matching** - Jobs across different regions of Indonesia

## Expanded Features
6. **Verified Companies** - Trust and safety for job seekers
7. **Resume Builder** (planned)
8. **Job Application Tracking** - Track applied jobs status
9. **Course Enrollment** - Enroll in training courses

## Pages
- Landing Page (/) - Full marketing landing page
- Dashboard (/dashboard) - Analytics overview with charts
- Jobs (/jobs) - Job search with filters and detail dialogs
- Skill Advisor (/skill-advisor) - AI skill gap analysis
- Training (/training) - Course catalog with enrollment

## Tech Stack
- React + Tailwind CSS + shadcn/ui
- Framer Motion for animations
- Recharts for data visualization
- React Router for navigation

## Data
All data is MOCKED on the frontend (no backend API calls). This is a frontend prototype.
